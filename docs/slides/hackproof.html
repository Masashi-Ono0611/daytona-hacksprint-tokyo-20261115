How it works

Read → Gate → Run → Receipt

1
Read

It reads the README.

A planner suggests how to run it and which claims to check.

2
Gate

Only allow-listed commands run.

README text never becomes a free command.

3
Run

One new Daytona sandbox per submission.

No secrets inside. Deleted after.

4
Receipt

Command, exit code, measured value, commit, sandbox id, SHA-256.

Exit codes and measurements decide. Not an LLM.
